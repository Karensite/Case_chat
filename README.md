# رابط گفت‌وگوی Case

`ai-chat.html` رابط سادهٔ فارسی برای API مدل آموزشی خودساخته در مخزن `karen-ai-api` است. در تنظیمات صفحه، آدرس پایهٔ سرور را خودتان وارد و ذخیره کنید؛ پیش‌فرض عمداً خالی است و نشانی ساختگی یا سرور زنده‌ای ثبت نشده است. آدرس در localStorage همان مرورگر ذخیره می‌شود. رابط وضعیت اتصال، انتظار، خطا و پاسخ را نشان می‌دهد و هیچ توکن مدیریتی ندارد.

سرور و رابط را جداگانه اجرا/میزبانی کنید. اگر رابط از origin دیگری باز می‌شود، همان origin دقیق را در `ALLOWED_ORIGINS` سرور مجاز کنید. اجرای GitHub Pages یا ذخیرهٔ این فایل در GitHub به‌تنهایی API را آنلاین نمی‌کند؛ سرور باید جداگانه deploy شود. جزئیات آموزش، اجرا و محدودیت واقعی مدل در README مخزن API آمده است. این مدل کوچک آموزشی درک معنایی ندارد.
